== The words we throw around

[%step]
[cols="1,3", options="header"]
|===
| Term | What it actually is
| *Terminal* | The window/emulator — draws text, sends keystrokes
| *Shell* | The program inside it — bash, zsh, fish
| *CLI* | One command, args in → result out → exits
| *REPL* | Read-Eval-Print-Loop — stays open, interactive
| *TUI* | Text UI — full-screen, panels, keys, redraws
|===

[data-timing=30]
=== Terminal vs Shell

[%step]
* *Terminal* = the glass. Renders characters, forwards input.
* *Shell* = the brain. Parses what you type, runs programs.
* You can swap either independently — different terminal, same shell.

[%step]
[.lead]
The terminal is the screen. The shell is the app.

[data-timing=30]
=== CLI vs REPL

[source,bash]
----
# CLI: run, print, exit
$ ls -la
$ git commit -m "..."

# REPL: stays alive, keeps state
$ python
>>> x = 40
>>> x + 2
42
----

[%step]
CLI = fire and forget. REPL = a conversation.

[data-timing=30]

=== AI agents love CLIs

[%step]
* Agents don't click buttons — they *run commands*

[%step]
