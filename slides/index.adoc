[data-timing=30]
=== Terminal vs Shell

[%step]
* *Terminal* = the glass. Renders characters, forwards input.
* *Shell* = the brain. Parses what you type, runs programs.
* You can swap either independently — different terminal, same shell.

[%step]
[.lead]
The terminal is the screen. The shell is the app.

[data-timing=30]
=== CLI vs REPL

[source,bash]
----
# CLI: run, print, exit
$ ls -la
$ git commit -m "..."

# REPL: stays alive, keeps state
$ python
>>> x = 40
>>> x + 2
42
----

[%step]
CLI = fire and forget. REPL = a conversation.

=== AI agents love CLIs

[%step]
* Agents don't click buttons — they *run commands*
* Text in, text out = the perfect tool interface
* A good CLI is instantly an AI-usable tool
* Composable tools > one giant app

[%step]
[.lead]
If it works in a pipe, it works for an agent.

[data-timing=45]
=== Quarkus makes it extra smooth

[%step]
* *Quarkus command mode* — CLIs as first-class apps
* *GraalVM native image* — instant startup, tiny footprint
* No JVM warmup tax on every invocation
* Perfect for agent tools + short-lived CLI runs

[%step]
[.lead]
Native CLIs: fast enough that an agent can call them all day.
