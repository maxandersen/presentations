== "But what about the craft?"

The craft is not the typing. +
The craft is:

[%step]
* Knowing *what* to build
* Knowing *why*
* Knowing when the answer is wrong
* Knowing when to throw it away
* Caring about the people who'll maintain it next

[.fragment]
A model can suggest. +
It cannot *care*.

[NOTE.speaker]
--
This is the emotional turn of the talk. Slow down here.
--

== Reading code is the new writing code

[%step]
* You will read more code you didn't write
* You will review code no human wrote
* "Looks right" is no longer good enough
* Code review skill becomes a *survival* skill

[.fragment]
If you only learned to *write*, you only learned half the job.

[NOTE.speaker]
--
Practical takeaway. The skill investment shifts toward reading & reviewing.
--

== Taste is the new bottleneck

[.fragment]
When everyone can generate code, +
the differentiator is *what you choose to keep*.

{nbsp}

[%step]
* Taste in architecture
* Taste in API design
* Taste in *what not to build*
* Taste in when to stop

[NOTE.speaker]
--
"Taste" is deliberately squishy. It's judgment + experience + values.
This is what cannot be prompted into existence.
--
