== "You Are Not Your Code"

Why does this shift feel *personal*?

[%step]
* We learned to identify with what we type
* "I am a Java developer." "I am a backend dev."
* Years of mastery — keystroke by keystroke
* A tool that types *for* you feels like a tool typing *over* you

[NOTE.speaker]
--
Name the emotional core. The fear is not irrational.
This is identity, not just workflow.
--

== Code is the artifact, not the job

[.columns]
=== Before

* Type code
* Read code
* Debug code
* Review code

=== After

* *Decide* what code
* *Direct* the generation
* *Verify* it's correct
* *Own* the outcome

[.fragment]
The verbs got bigger. +
The responsibility got bigger.

[NOTE.speaker]
--
This is the title-of-the-talk slide. Land it slowly.
The craft is not the typing — it's the judgment, the choosing, the owning.
None of those got easier.
--
