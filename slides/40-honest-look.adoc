== What AI is actually good at (today)

[%step]
* Boilerplate, scaffolding, glue code
* "How do I do X in library Y" — faster than docs
* Test cases you would have skipped
* Renames, refactors, format conversions
* Explaining unfamiliar code
* First drafts of almost anything

[NOTE.speaker]
--
Be concrete. Audience needs to recognise their own workflow.
--

== What AI is still bad at (today)

[%step]
* Knowing what it *doesn't* know
* Long-range consistency in a big codebase
* Your team's unwritten conventions
* Saying "this is a bad idea, don't build it"
* Being accountable when it's wrong

[.fragment]
Notice: the bad-at list is *exactly* the senior-engineer list.

[NOTE.speaker]
--
This is the slide that lands with skeptics.
Their value didn't disappear — it got *more* concentrated.
--
